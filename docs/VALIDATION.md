# AeroCast NCR - Validation & Honest Benchmark Protocol

## Scientific Validation Standards
1. **Independent CPCB Station Validation**: Predictions generated by Tier 1 data models are cross-evaluated against ground-truth CPCB monitoring stations (Tier 2).
2. **Horizon-Specific Degradation Tracking**: Performance metrics are evaluated independently for $1\text{h}, 6\text{h}, 12\text{h}, 24\text{h}, 48\text{h},$ and $72\text{h}$ horizons to document error growth curves.
3. **No Synthetic / Hardcoded Demo Fallbacks**: All dashboard metrics must reflect real inference or API returns. Zero dummy AQI numbers will be passed silently.

## CPCB AQI Calculation Validation
Indian AQI is computed using the CPCB 8-sub-index breakpoint algorithm:
- Pollutants considered: $\text{PM}_{2.5}$ (24h avg), $\text{PM}_{10}$ (24h avg), $\text{NO}_2$ (24h avg), $\text{O}_3$ (8h avg), $\text{SO}_2$ (24h avg), $\text{CO}$ (8h avg).
- AQI value = $\max(\text{Sub-Index}_i)$.
- Categories:
  - Good ($0-50$)
  - Satisfactory ($51-100$)
  - Moderate ($101-200$)
  - Poor ($201-300$)
  - Very Poor ($301-400$)
  - Severe ($401-500$)
  - Severe+ ($>500$)
